# VILEORUF CRM — материалы передачи

Этот манифест определяет финальный набор desktop-скриншотов. Все изображения сняты из текущего UI в разрешении 1440 × 900 с использованием только одноразовых синтетических/демонстрационных данных. Изображения служат визуальным доказательством, но не подтверждают выполнение операций провайдера. `01-public-request.png` требует повторной съёмки владельцем после изменения маркера обязательности Email; не заменяйте предоставленное владельцем изображение синтетической съёмкой.

| Файл | Визуальное подтверждение в текущем UI |
|---|---|
| `01-public-request.png` | Брендированная форма публичной заявки, маркер обязательности Email и граница согласия (требуется повторная съёмка владельцем). |
| `02-dashboard.png` | Операционный dashboard. |
| `03-clients.png` | Реестр Client и переключатель Active/Archived. |
| `04-client-detail.png` | Компактная Client Card с операционными элементами управления и элементами дочерних процессов. |
| `05-client-communications.png` | Диалог коммуникаций Client: действия расположены перед историей. |
| `06-deals.png` | Таблица Deals с привлекательностью и вероятностью. |
| `07-deal-detail-ai.png` | Операционные действия Deal Card и представление AI. |
| `08-deal-communications.png` | Диалог коммуникаций Deal: действия расположены перед историей. |
| `09-email-draft.png` | Ручная и AI-области Deal Email Draft, действия с сохранённым черновиком. |
| `10-calendar.png` | Создание события перед историей и компактная строка действий Calendar event. |
| `11-pipeline.png` | Pipeline/Kanban. |
| `12-tasks.png` | Tasks. |
| `13-inbox.png` | Поток Inbox/несопоставленных коммуникаций. |
| `14-ai-history.png` | Раскрываемая AI History. |
| `15-analytics.png` | Операционная аналитика CRM. |
| `16-business-settings.png` | Список Category/Service и UX модального окна. |
| `17-integrations.png` | Безопасные статусы интеграций и WhatsApp вне MVP. |
| `18-employees.png` | Отдельная страница ADMIN Employees. |

Предыдущий набор из девяти изображений создан до финальной доработки UI и изолирован в `legacy-pre-polish/`; его нельзя представлять как финальное доказательство. На финальных скриншотах не должны быть видны пароли, токены, учётные данные/идентификаторы провайдера, реальные персональные данные, инструменты браузера или реальные операции провайдера.
